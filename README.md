# Retail Sales Analytics Dashboard

## Project Overview

This project demonstrates an end-to-end Retail Sales Analytics workflow using Python, SQL, Power BI, and AWS.

The objective is to analyze retail sales data to identify sales trends, product performance, regional performance, and profitability insights.

---

## Dataset

The dataset contains retail sales transactions with the following fields:

* Order ID
* Order Date
* Region
* Category
* Product
* Sales
* Profit

Location:

`data/sales_data.csv`

---

## SQL Analysis

SQL queries are used to analyze:

* Total sales by region
* Profit by category
* Top-selling products
* Monthly sales trends
* Overall business performance

Location:

`sql/analysis_queries.sql`

---

## Python Analysis

Python and Pandas are used to perform:

* Data exploration
* Summary statistics
* Regional sales analysis
* Category profitability analysis
* Product performance analysis

Location:

`notebooks/retail_sales_analysis.ipynb`
